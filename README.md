# EDS 223 - Assignment 1 - EJ Spatial Analysis: Hazardous Waste Facility Proximity and Low-Income Communities in Alameda County
This repository houses the analysis for an Environmental Justice spatial project that visualized percentile of hazardous waste facility proximity and percentile of the share of low-income residents in block groups in Alameda County (ranked against all block groups in California) to compare how the two are distributed.

## Data Access
The data for this project was taken from the United States Environmental Protection Agency's (EPA) Environmental Justice Screening and Mapping tool (version 2.2) from 2023. This tool is now defunct and cannot be accessed from the EPA. However the data used here can be accessed at the following link: [Zipped Data Folder](https://drive.google.com/file/d/1nG6Nj1bXfzQFOVMO8Km3eNy4SWu1YcIQ/view)
